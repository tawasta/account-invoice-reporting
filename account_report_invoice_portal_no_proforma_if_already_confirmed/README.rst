===============================================================
Invoice Report - No 'Proforma' in Portal for Confirmed Invoices
===============================================================

* By default Odoo shows invoices in the customer portal as "PROFORMA" until
  the official PDF has been generated and stored with "Send & Print"
* This module renders posted invoices in the portal (preview and download)
  as normal invoices without the PROFORMA prefix in the PDF even 
  when "Send & Print" is never used
* The PDF is rendered on the fly and not stored
