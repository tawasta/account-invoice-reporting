===============================================================
Invoice Report - No 'Proforma' in Portal for Confirmed Invoices
===============================================================

* By default Odoo shows invoices in the customer portal as "Proforma Invoice"
  until the official PDF has been generated and stored with "Send & Print"
* This module renders posted invoices in the portal (preview and download)
  as normal invoices without the "Proforma" title, even when "Send & Print"
  is never used

Configuration
=============
* None needed

Usage
=====
* Open a posted invoice in the portal and preview or download the PDF
