=======================================
Invoice – Payment reminder PDF template
=======================================

Adds a new QWeb template, Payment reminder, for invoices.

Configuration
=============
A user does not need to configure anything

Usage
=====
Install the module and select an invoice to print out Payment Reminder

Known issues / Roadmap
======================
Be wary about the t-if changes that this module does. Some
other modules may try to modify those same t-if clauses.
