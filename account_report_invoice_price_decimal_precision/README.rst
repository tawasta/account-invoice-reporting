====================================================
Account Invoice PDF report - Price decimal precision
====================================================

* Sets invoice lines' unit price as monetary field on the
  invoice PDF print


Configuration
=============
* The decimal precision can be configured in currency rounding factor
  in Invoicing -> Settings -> Currencies

Usage
=====
* Just print an invoice PDF
