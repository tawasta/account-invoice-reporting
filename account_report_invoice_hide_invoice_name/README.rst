==========================================
Account invoice report - Hide invoice name
==========================================

* Configurable option for hiding invoice name (e.g. "Invoice INV/2025/0001") on 
  invoice PDF

Configuration
=============
* Check "Hide invoice name" at the Invoice settings. Note that the setting
  is company-specific in multicompany environments

Usage
=====
* Just print an invoice. The name field gets hidden
